3. Prosody + Isochrony (DSP baseline)

"Baseline + Prosody + Isochrony" mode applies a DSP baseline, NOT a trained neural mapping network (no parallel EN-MR prosody training data exists yet) — see TECHNICAL_REPORT.md §6 for what this is and isn't. Prosody: rescales the TTS output's F0 register to match the source English audio's pitch statistics (WORLD analysis-resynthesis), plus loudness matching. Isochrony: time-stretches output to the source's duration if outside +/-15% tolerance.

3.1 10-sample stress test: baseline vs. enhanced

Same 10 sentences as §2, each enhanced using one fixed source clip as the prosody/duration reference — a stress test (forces unrelated sentences toward one target duration, producing more extreme stretch ratios than a real per-utterance run needs; §6.3's real pipeline run needed no stretch at all). Important: the "10/10 compliant" duration number below does not mean 10/10 sound good — reading the round-trip transcriptions, 2 of the most-stretched samples (ratio < 0.5, over ~2x stretch) show clear failures (non-Marathi gibberish, or an empty transcription). See TECHNICAL_REPORT.md §6.5 for the full breakdown.

3.2 Full formal evaluation (BLEU / chrF++ / MCD / F0-RMSE+correlation / ECAPA speaker similarity / duration compliance)

Same 10 samples, now scored against the real ground-truth recording of the same speaker saying the same sentence (confirmed present in the IISc SYSPIN dataset for all 10) — the standard objective-TTS-eval setup, not just an internal baseline-vs- enhanced ablation. BLEU/chrF++ reuse the round-trip ASR transcriptions already shown above, scored against the known-correct target text.

Headline finding: enhanced is measurably worse than baseline on 4 of 5 quality metrics — MCD, F0-RMSE, F0 correlation, and ECAPA speaker similarity all degrade, the speaker similarity drop is especially large (0.85 → 0.31). It only wins on duration compliance, the one thing it directly targets. This is consistent with §3.1's finding that the stress test's extreme stretch ratios push the phase-vocoder well past graceful degradation — see TECHNICAL_REPORT.md §6.6 for the full discussion, not just the chart.
